# ARMANI: однаковий TOP RP у Discord та на сайті

Пакет підготовлений із вашого armani(4).py. Нічого ще не запущено й не опубліковано від вашого імені.

Джерело рейтингу — таблиця users у локальному armani_bot.db. Порядок збігається з /top_armani: rp_balance DESC, contract_rp_earned DESC, user_id ASC. Сайт показує ті самі 10 позицій. Показуємо RP, а не новий окремий XP. Нарахування за контракти та списання залишаються у вашому боті; синхронізація лише читає дані.

## 0. Замініть надісланий токен

У Discord Developer Portal відкрийте ваш застосунок → Bot → Reset Token. Новий токен додавайте тільки у локальний .env або секретні змінні хостингу бота. Не вставляйте його у Vercel, GitHub чи чат.

## 1. Supabase

Ви вже виконали 01-schema.sql попереднього пакета. Тепер SQL Editor → новий запит → вставте весь `setup/03-rp-ranking.sql` → Run.

Це створить окремі таблиці RP та функцію приймання рейтингу. Загальне місце сім’ї, кількість авто та вручну задані показники не змінюються. Дати народження, скриншоти контрактів та історія витрат на сайт не передаються. Публікуються Discord ID, відображуване ім’я, баланс, зароблені контрактами RP і позиція.

## 2. Файли сайту у GitHub

Цей пакет — доповнення до попереднього armani-admin-update.zip. Якщо попередній пакет ще не опубліковано, установіть його першим.

У репозиторії сайту `shavera149/Armani-vercel`:
- замініть кореневий `dashboard.js` файлом `website/dashboard.js`;
- додайте `website/api/rp-sync.js` як `api/rp-sync.js`.

Папку website створювати в репозиторії не треба — завантажуйте її ВМІСТ. Не завантажуйте туди папку bot, токен або базу .db. Решта сайту залишається на місці.

## 3. Секрет зв’язку та налаштування Vercel

У терміналі свого комп’ютера створіть окремий секрет:

```powershell
py -c "import secrets; print(secrets.token_hex(32))"
```

Збережіть результат приватно. Це BOT_SYNC_TOKEN; він НЕ є токеном Discord.

Vercel → ваш проєкт → Settings → Environment Variables, середовище Production:

| Назва | Значення |
| --- | --- |
| BOT_SYNC_TOKEN | Згенерований секрет |
| DISCORD_GUILD_ID | 1555649348501770351 |
| SUPABASE_SECRET_KEY | sb_secret_… із Supabase вашого проєкту |

Використовуйте серверний secret key Supabase, не sb_publishable_… з фронтенду. Після додавання змінних зробіть Redeploy останньої версії. Нікуди не вставляйте тут Discord-токен.

## 4. Файли бота на комп’ютері

Зупиніть старий процес бота: Ctrl+C у його терміналі. Збережіть резервну копію папки та armani_bot.db. Якщо поруч є armani_bot.db-wal і armani_bot.db-shm, збережіть їх також. Не запускайте дві копії бота одночасно.

Із папки bot цього архіву скопіюйте у папку свого бота:
- armani.py — новий основний файл;
- website_sync.py — модуль передачі рейтингу;
- requirements.txt;
- .env.example та .gitignore.

Ваш наявний armani_bot.db повинен бути в ТІЙ САМІЙ папці, що й armani.py. Не створюйте нову порожню базу замість наявної, інакше поточні бали не з’являться. У новій версії шлях до бази прив’язаний до розташування armani.py.

Створіть копію .env.example з назвою `.env` (саме так, без .txt) і заповніть:

```env
DISCORD_TOKEN=новий_токен_із_Discord_Developer_Portal
BOT_SYNC_TOKEN=той_самий_секрет_що_у_Vercel
```

DISCORD_GUILD_ID вже заданий у Python як GUILD_ID=1555649348501770351. Секретний ключ Supabase боту не потрібен.

## 5. Запуск у VS Code на Windows

Відкрийте папку бота → Terminal → New Terminal. Python 3.10 або новіший.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe armani.py
```

Якщо Python не встановлено, встановіть його з python.org. На macOS/Linux використовуйте python3 та .venv/bin/python.

Оскільки ваш бот використовує учасників і скриншоти з повідомлень, у Developer Portal → Bot увімкніть Server Members Intent та Message Content Intent. Бот має бути доданий саме на сервер 1555649348501770351; ID застосунку/бота — 1555591785630146721. Залиште наявні права для ролей, нікнеймів, каналів контрактів та повідомлень; роль бота повинна бути вище ролей, якими він керує.

Успіх передачі: `[ARMANI SITE] TOP RP передано на сайт.` Бот опитує базу кожні 30 секунд, сайт — кожні 30 секунд, тому за нормального зв’язку оновлення видно приблизно за хвилину. У разі помилки знімок повторюється; наступні зміни підтягнуться після відновлення зв’язку. Не закривайте термінал; після вимкнення комп’ютера синхронізація зупиниться. Постійний хостинг бота має зберігати armani_bot.db на постійному диску. Сам Vercel використовується лише для API сайту.

## 6. Перевірка

1. Відкрийте /top_armani у Discord і порівняйте із сайтом.
2. Після звичайного затвердження контракту або списання RP зачекайте приблизно хвилину й перевірте обидва топи.
3. Перевірте дату під таблицею сайту: вона показує останню синхронізацію. Якщо бот вимкнений, останні дані залишаються видимими.

| Помилка у терміналі бота | Що перевірити |
| --- | --- |
| HTTP 404 | api/rp-sync.js відсутній у Production deployment |
| HTTP 401 | BOT_SYNC_TOKEN відрізняється у Vercel та .env |
| HTTP 503 | Не всі три змінні Vercel заповнені або немає Redeploy |
| HTTP 400 | DISCORD_GUILD_ID неправильний або дані RP поза діапазоном |
| HTTP 502 | SQL 03-rp-ranking.sql не виконаний або неправильний SUPABASE_SECRET_KEY |
| Заповніть BOT_SYNC_TOKEN | .env відсутній або секрет коротший за 32 символи |
| LoginFailure | Перевірте новий DISCORD_TOKEN локально, не надсилайте його |

Порожній топ означає, що у users для цього сервера ще немає записів, або взято не ту базу. Імена на сайті беруться з Discord display_name; якщо учасник недоступний у кеші, показується його Discord ID. Зміна профілю на сайті сама по собі не змінює Discord-нікнейм.

## Що перевірено

Перевірено Python/JavaScript-синтаксис, SQL-запит до тимчасової SQLite, порядок однакових балансів, вплив списання, ізоляцію сервера та ліміт топ-10. Імітовані тести API перевіряють авторизацію, валідацію, формат виклику Supabase та обробку помилок. SQL Supabase і реальний запуск Discord не виконувалися — потрібні ваші налаштування та запуск. Основна контрактна логіка вашого файлу не переписувалася й окремо не перевірялася.

Документація фонового циклу: https://discordpy.readthedocs.io/en/stable/ext/tasks/index.html
