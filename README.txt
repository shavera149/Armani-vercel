ARMANI — каталог автопарку з редактором

УСТАНОВЛЕННЯ
1. Відкрийте 06-fleet-catalog.sql. Скопіюйте ВЕСЬ текст у Supabase > SQL Editor > New query > Run.
   Очікуваний результат: Success. No rows returned.
   Завантаження SQL у GitHub не виконує його в Supabase.
2. Замініть у корені GitHub-репозиторію три файли:
   index.html
   dashboard.js
   fleet.js
   Назви мають бути точними, без (1). Старі portal.js, auth.js та інші файли залиште.
3. Commit changes. Дочекайтеся успішного розгортання Vercel. Оновіть сайт через Ctrl+F5.

РЕДАГУВАННЯ
Увійдіть через Discord як адміністратор. Автопарк > Редагувати.
Можна змінити назву, опис, категорію, кількість, мінімальний ранг, потужність,
двигун, привід, максимальну швидкість, розгін 0–100, салон, місце знаходження,
номери та фото. Кожен номер вводиться з нового рядка. Натисніть «Зберегти для всіх».
Фото: JPG, PNG, WebP до 5 МБ. Без вибору нового файлу поточне фото зберігається.
Швидкість 0 показується як «Уточнюється». Початкові характеристики потрібно заповнити.

Категорії фільтрів автоматично формуються з введених значень.
Лічильник категорії — сума кількості автомобілів у ній.
На великих екранах — 4 колонки, на середніх — 2, на телефонах — 1.
Усі характеристики зберігаються в Supabase (armani_media.vehicle_specs).
Наявні політики доступу не змінюються: редагує лише адміністратор.
Скриншоти маєтку, дрескод, вищий склад і рейтинг залишаються у наявних розділах.

ПЕРЕВІРКА
Перевірено синтаксис JavaScript і DOM-логіку: редактор, перевірка значень,
запит збереження, номери, категорії, фільтри, захист від HTML у текстах,
збереження старого фото та блокування запису без прав адміністратора.
Оновлення бази та публікація виконуються у ваших Supabase/GitHub/Vercel.
